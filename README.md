# Actividad 9 · Firebase Authentication

Abrí el proyecto mediante un servidor local, por ejemplo Live Server. Antes de probarlo:

1. Creá tu proyecto en Firebase y registrá una aplicación web.
2. Habilitá Authentication > Sign-in method > Correo electrónico/contraseña.
3. Copiá la configuración de tu proyecto en `js/firebase/config.js`.
4. Completá los dos bloques de `js/panel.js`.

No subas contraseñas personales al repositorio.
